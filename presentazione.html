Architettura
Come Funziona
Il motore NLP pattern-based
1

Input utente

L'utente scrive una domanda in linguaggio libero

2

NLP pattern

Regex ed euristica riconoscono l'intenzione (circolare, evento, materia…)

3

Query dati

Il motore interroga circolari.json, materiali.json, eventi.json

4

Risposta

Il bot genera HTML ricco: card, date, allegati, autori

Tutto il riconoscimento avviene lato client — nessuna chiamata a server esterni o API di intelligenza artificiale. Il bot funziona completamente offline.
